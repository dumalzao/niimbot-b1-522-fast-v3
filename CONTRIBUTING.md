# Como contribuir

Este é um experimento de firmware com **risco de inutilizar dispositivos**. Mudanças de código devem continuar **reprodutíveis**, limitadas a offsets documentados e acompanhadas de hashes.

Ao abrir um Issue ou Pull Request, compartilhe:

- Modelo e revisão física do hardware (se verificável).
- Firmware original e o hash da imagem de entrada (sem anexar o binário).
- Versão do gerador utilizada e hash SHA-256 da saída.
- Dimensão e tipo da etiqueta (com/sem RFID).
- Relato separado de velocidade, escala horizontal/vertical, contraste e software usado para imprimir.
- Comandos e erros necessários para reprodução, após **remover números de série, MAC e dados pessoais**.

Não publique firmware proprietário, arquivos de bootloader extraídos, segredos ou arquivos pessoais. Evite sugerir flash entre famílias principais de firmware. Não apresente resultados de uma única unidade como certificação geral.
